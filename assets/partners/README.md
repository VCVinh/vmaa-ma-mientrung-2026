# Partner logo slots (KV_Hero_Motion_v2.html)
Drop white or single-colour PNG/SVG logos here (transparent background, max 60 px tall at 1920x1080).
Register them in the HTML before the script runs:

    window.PARTNERS = {
      "sponsor-main": ["../assets/partners/a.png"],
      "sponsor-gold": ["../assets/partners/b.png", "../assets/partners/c.png"],
      "academic":     ["../assets/partners/due.png"],
      "support":      [], "media": []
    };

Slots: organizer (330x64), sponsor-main / sponsor-gold / academic (440x64), support / media (466x64).
Logos are auto-converted to white. Preview slot outlines with ?guides=1.
