## 1. Executive Summary

This repository implements the **International Motion Identity System**, transitioning the event from disconnected visual experiments to a unified, prestigious global visual communication language:
1. **Stage 01 · Creative Intelligence:** "Architecture of Value" treatment, obsidian-cobalt color palette, deterministic typography with Plus Jakarta Sans, unclipped Vietnamese diacritics.
2. **Stage 02 · Controlled AI Visual Generation:** Clean Pha Lê optical plates (`clean_phale_master_4k.png`), fluted crystal column caustics, and cinematic depth maps produced under strict seed control.
3. **Stage 03 · Designed Motion:** 3D procedural forms, Blender plinth choreography, Motion Canvas / GSAP lower-thirds, and deterministic typography rendering.
4. **Stage 04 · Finishing & Venue Delivery:** 4K UHD masters, 32:9 curved stage LED backdrops, 9:16 vertical reels/stories, and contact sheets calibrated for high-lumen ambient stage environments.

## 3. Production Script Mapping

- `build_perfect_phale_suite.py`: Re-renders all Key Visual variants and social posts using the pure Pha Lê plate, completely eliminating legacy ghost text.
- `render_contact_sheet_phale.py`: Generates the 3840×2160 4K UHD Master Contact Sheet.
- `generate_gallery.py`: Compiles the interactive HTML5 preview gallery.
- `blender_architecture_of_value.py`: Procedural Blender Python script creating the 3D crystal prism motif and camera orbit.
- `record_vip_motion_plinth_video.py`: Headless browser video recorder for animated VIP invitation cards.

## 4. Quality Standards & Jury Protocol

Every render complies with the **Anti-AI-Artifact Law**:
- All brand marks, speaker names, numerical figures, and event dates are rendered deterministically using real vector/web fonts.
- Vietnamese diacritics maintain optical headroom above uppercase letters (`MIỀN TRUNG`, `ĐÀ NẴNG`).
- Contrast ratios exceed 7:1 against background caustics.
