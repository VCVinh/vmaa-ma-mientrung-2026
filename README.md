## 🏛️ 2. Ý Niệm Sáng Tạo: "Architecture of Value" (Kiến Trúc Giá Trị)

Nhận diện hình ảnh và chuyển động của sự kiện chuyển dịch toàn diện từ những thử nghiệm AI đơn lẻ sang một **hệ thống nhận diện hội nghị quốc tế thống nhất**:
1. **Kiến trúc Pha Lê khúc chiết (Pha Lê System):** Các cột trụ thủy tinh xếp nếp (fluted optical crystal columns) vươn cao trong không gian sâu thẳm, tượng trưng cho cấu trúc thể chế minh bạch, dòng vốn đầu tư bền vững và sự hội tụ công nghệ cao.
2. **Bảng màu Obsidian — Cobalt tinh khiết:**
   - **Deep Obsidian / Midnight Navy:** `#030712`, `#060D1F` (tối ưu hóa độ tương phản và chiều sâu sân khấu).
   - **Saturated Cobalt Blue:** `#1D4ED8`, `#2563EB` (năng lượng công nghệ và sự quyết đoán).
   - **Ice Cyan & White Specular:** `#93C5FD`, `#FFFFFF` (ánh sáng khúc xạ quang học từ đỉnh vương miện pha lê).
3. **The Anti-AI-Artifact Law & Deterministic Typography:**
   - Tuyệt đối không để AI render text, ngày tháng, logo hoặc số liệu.
   - 100% typography, logo VMAA, tên diễn giả và thông điệp được render **chính xác tuyệt đối** bằng code (SVG, Playwright 2x/4K, CSS3, GSAP) trên font chữ tiêu chuẩn **Plus Jakarta Sans**, bảo toàn toàn vẹn dấu tiếng Việt (`MIỀN TRUNG`, `ĐÀ NẴNG`, `BẤT ĐỘNG SẢN`).

## 🚀 6. Hướng Dẫn Vận Hành (How to Run)

### Cài đặt môi trường:
```bash
pip install -r requirements.txt
playwright install chromium
```

### Kết xuất lại toàn bộ hệ thống hình ảnh Pha Lê:
```bash
# 1. Kết xuất bộ Key Visuals và Social Media Posts:
python build_perfect_phale_suite.py

# 2. Kết xuất Contact Sheet 4K tổng hợp:
python render_contact_sheet_phale.py

# 3. Cập nhật lại thư viện Gallery Preview:
python generate_gallery.py
```
